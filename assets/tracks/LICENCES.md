# Audio Track Licences

All bundled tracks must be cleared for use in a distributed mobile application
before the production build is submitted to the App Store / Play Store.

## Format requirements
| Field | Requirement |
|---|---|
| Format | MP3 |
| Bitrate | 128 kbps |
| Max size | 5 MB per file |
| Duration | ≥ 60 seconds |
| Loop | Clean loop point (no audible gap) |

## Recommended sources

- [Pixabay Music](https://pixabay.com/music/) — no attribution required, free for commercial use
- [Free Music Archive](https://freemusicarchive.org) — filter by CC0 or CC-BY licence
- [Bensound](https://www.bensound.com) — free plan requires attribution; paid plan removes it

Run `scripts/download-audio.sh` after filling in URLs, or
run `scripts/generate-placeholder-audio.sh` for silent placeholders during development.
