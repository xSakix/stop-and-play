# Default Tracks

Place royalty-free looping MP3 files here with these exact names:

- `groove.mp3`
- `party.mp3`
- `dance.mp3`

These map to the bundled default tracks shown in the music picker.
All three files must be present before building; remove or comment out
unused entries in `src/audio/AudioManager.ts` if you have fewer tracks.

Recommended sources for royalty-free loop audio:
- https://freemusicarchive.org
- https://www.bensound.com
- https://pixabay.com/music
